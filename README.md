**Efficacious Novel Intrusion Detection System for Cloud Computing Environment**
**Technologies:** Java, HTML, CSS, JavaScript, Servlet/JSP, MySQL, JDBC, Apache Tomcat

Developed a web-based Intrusion Detection System (IDS) to identify and detect malicious activities in a cloud computing environment. The system analyzes network and user-related data to classify normal and suspicious activities. Feature Selection using the **Firefly Algorithm** was implemented to select relevant features, while a **hybrid algorithm with Decision Tree** was used for effective intrusion classification. The system helps improve detection accuracy and provides a more efficient approach to identifying potential security threats in cloud environments.
